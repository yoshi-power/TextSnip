TextSnip 0.1.0 — Windows 화면 텍스트 복사

1. ZIP 파일을 먼저 모두 압축 해제하세요.
2. TextSnip 폴더에서 Start.cmd를 두 번 클릭하세요.
3. 설정 창에 표시된 단축키를 확인하세요. 기본값은 Ctrl + Shift + Q입니다.
4. 복사할 글자를 드래그하세요.
5. 복사 완료 알림 후 Ctrl + V로 붙여넣으세요.

TextSnip.exe를 직접 실행하면 트레이에서 대기합니다.
설정 창의 X 버튼은 앱을 종료하지 않습니다.
작업 표시줄의 TextSnip 아이콘을 더블 클릭하면 설정을 다시 엽니다.
종료: 트레이 아이콘 우클릭 > TextSnip 종료.

지원 환경: Windows 10/11, .NET Framework 4.8 권장.
Windows x64 환경에서 검증했습니다. macOS/Linux는 지원하지 않습니다.
설치 프로그램, API 키, 유료 구독은 필요하지 않습니다.

이미지 OCR 언어가 없다고 나오나요?
- 앱 원문을 가져올 수 있는 화면은 OCR 언어 없이도 사용할 수 있습니다.
- 이미지·영상 OCR에는 해당 Windows OCR 언어 팩이 필요합니다.
- Install-OCR.cmd를 실행하면 한국어·영어·일본어 OCR 설치를 돕습니다.
- 이 단계에는 인터넷과 Windows 관리자 승인이 필요하며 시간이 걸릴 수 있습니다.
- 설치 후 트레이에서 TextSnip을 종료했다가 다시 실행하세요.
- 회사 PC에서는 관리자 정책으로 설치가 제한될 수 있습니다.

정확도
- '원문 복사 완료': 앱에서 실제 텍스트를 가져왔습니다.
- 'OCR 복사 완료': 이미지를 인식했습니다. 글꼴·화질에 따라 오류가 남을 수 있습니다.
- 원문 접근성이 없는 앱은 자동으로 OCR을 사용합니다.
- 숫자·코드 등은 필요에 따라 설정의 '여러 줄도 읽기 편하게'를 끄세요.
- 결과 창을 띄우지 않고 바로 클립보드에 복사합니다.

보안 및 개인정보
- 앱은 화면이나 텍스트를 외부 서버로 보내지 않습니다.
- Windows 클립보드 기록·동기화 설정은 별도로 적용됩니다.
- 이 초기 배포본은 코드 서명되지 않았으므로 Windows에서 경고할 수 있습니다.
- 출처와 함께 제공된 SHA256을 확인하세요. PC의 보안 기능을 끄지 마세요.

TextSnip.exe와 Ocr.ps1은 같은 폴더에 두세요.
설정은 %LOCALAPPDATA%\TextSnip\settings.txt에 저장됩니다.
삭제하려면 앱을 종료한 뒤 압축을 푼 폴더를 지우면 됩니다.
